# WP Vue Shop (WordPress + WooCommerce)

WordPress + WooCommerce как бэкенд для Headless-магазина.

## Стек

- WordPress
- WooCommerce
- PHP 8.4
- MariaDB
- DDEV

## Возможности

- Каталог товаров через WooCommerce
- Категории и метки товаров
- REST API (Store API)
- CORS для Vue-фронтенда

## Запуск

```bash
git clone git@github.com:DmPe91/wp-vue-shop.git
cd wp-vue-shop
ddev start
ddev composer install
```
